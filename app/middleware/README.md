## Purpose

This folder is for middleware files.

Middleware can be used for request checks and route protection, such as:

- Authentication checks
- Admin access checks
- CSRF protection
- Maintenance mode
- Request filtering
- Rate limiting

## Default Demo Note

The default NoClass™ demo does not activate middleware automatically.

This keeps the starter application simple and allows developers to add middleware only when needed.
